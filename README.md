# Belchiken — Maquette interactive

Prototype mobile-first de l'expérience client et de gestion Belchiken, réalisé avec React et Vite.

## Lancer le projet

```bash
npm install
npm run dev
```

## Parcours inclus

- Accueil, menu filtrable et recherche de produits
- Panier interactif avec quantités et total estimé
- Choix livraison / retrait
- Portefeuille de démonstration et parcours Mobile Money / QR (sans transaction réelle)
- Fidélité, points et récompenses
- Profil client et assistant conversationnel simulé
- Aperçu d'un tableau de bord administration

## Important

Il s'agit d'une maquette de présentation avec des produits, montants, soldes et indicateurs fictifs. Aucun paiement, dépôt, retrait, compte client réel ou commande n'est connecté. Les tarifs, offres, règles de fidélité, contenus et éléments de marque doivent être validés avant toute mise en production.

## Stack

React 18 · Vite · Lucide React · CSS responsive
